The bottom panel's **Repos** tab answers "where is every agent, and how dirty is its tree" in one glance — one row per agent pane, grouped by repository.

## Rows

Each agent row shows:

- **Agent** — labeled and colored like the main list
- **Branch** — the branch checked out in the pane's working directory
- **Ahead / behind** — `↑N` / `↓N` counts vs. the configured upstream
- **Dirty count** — `~N` uncommitted paths (staged + unstaged + untracked) from `git status --porcelain`

Rows render only the movement that exists: a clean, synced branch shows no right-side cluster at all.

## Repo groups

Repos with multiple agents get a group header line, matching the grouping in the main agent list. Panes without resolvable git metadata are skipped.

## Data source

Everything comes from the sidebar's background git-info resolver, TTL-gated per path — the render thread never spawns git. Detailed staging work (add, commit, diff) happens in the agent pane itself, where `git` already runs.

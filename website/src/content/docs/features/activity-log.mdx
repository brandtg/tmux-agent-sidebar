The bottom panel's **Feed** tab is a single merged timeline across every agent pane — what tasks were created, which subagents spawned, what files were edited, and anything that needs you (permission prompts, questions, failures).

## What is recorded

Each row is one notable event: when it happened, which agent did it, and a label. Long labels wrap onto continuation lines aligned under the label column (and scroll), so nothing is cut off on narrow sidebars. The feed is deliberately sparse — read-only tool spam (`Read`, `Grep`, `Bash`, MCP calls) stays out because the agent pane itself shows it better.

Entries come from the same per-pane activity logs the hooks write (`$XDG_RUNTIME_DIR/tmux-agent-activity<pane>.log`, falling back to `/tmp`), plus lifecycle events the hooks append directly: a notification (`Notify`), a permission prompt or denial (`Permission`), and a failed turn (`Error`).

## What badges

The tab title shows `Feed ·N` when unseen events need you — permission prompts, failures, and agent questions. Routine work (edits, task churn) never badges. Opening the Feed clears the count; while the panel is minimized the badge keeps counting on the single header row.

## Per-pane detail lives elsewhere

- The agent row in the main list shows the last assistant message, subagents, and task progress.
- The agent pane itself shows full tool-call history.

## Agent coverage

| Agent       | Covered events                                        |
| ----------- | ----------------------------------------------------- |
| Claude Code | Tasks, subagents, edits, permission prompts, failures |
| Codex       | Permission prompts and failures (its `PostToolUse` fires for Bash alone) |
| OpenCode    | Tasks, subagents, edits, permission prompts, failures |

## Switching tabs

The bottom panel has two tabs — Feed and Repos. Swap with `Shift+Tab`, with `←`/`→` while the bottom panel has keyboard focus, or by clicking the tab label with the mouse. Press `?` for the keyboard reference.
